# Page Override · 房间（collection-room）

> 检索：先读 `../MASTER.md`，再读本文件。本文件规则优先于 MASTER，但**不得覆盖** MASTER §3 token 值、§7 合规 UI、§9 无障碍底线。
> 对应实现：`prototype-collection-room.html` ｜ 创建与发现规则以 MASTER v1.7 §20 为准；媒体功能定义：PRD §22 / §23 / §24

## 1. 页面定位

房间是**用户自建的小圈子与内容容器**，不是影视资源站。创建时默认 `general`（通用），类型可选、可后改；有内容的房间才进入目录，已加入房间可订阅更新通知。剧集、电影和视频是房间的可选展示形态：

| `room_type` | 编排 | 专属组件 | 上传控件 |
| `general` | 按时间排序的主题讨论与帖子 | `ContentCard` / `ActionBar` | **无文件上传** |
|---|---|---|---|
| `series` | 季 Tab + 固定集序 `S01E001` | `EpisodeRow` / `SeasonTabs` / `Progress` | **无** |
| `film` | 片单网格，按自定义顺序 / 年份 | `FilmCard`（纯色占位封面） | **无** |
| `video` | 缩略卡片列表 | `VideoCard` / `EmbedPlayerCard` | **仅原创视频房间有**，且强制版权确认 |

空房间创建不需要版权确认。房间顶部 `room-switch` chip 用 `--surface2` 底，选中态 `--text` 底 + `--bg` 字（与首页 Tab 的下划线式选中不同，这是**刻意的层级区分**：这是类型切换，不是视图 Tab）。

## 2. 页面级偏差（相对 MASTER）

| 项 | MASTER 默认 | 本页 override | 理由 |
|---|---|---|---|
| 栅格 | 240 / 1fr / 320 | 同 MASTER（**不再用 230 / 320**） | §2 一致性裁决 |
| 顶部标题 | 19px | 17px + 单行省略 | 房间名可能很长（剧名 / 季） |
| 图标按钮 | 44px | 44px（**保持，不退回 34px**） | 触控红线 |
| 封面字体 | `--font-sans` | `--font-serif`（`Noto Serif TC` / `Songti SC`），30px，`letter-spacing:4px` | 影视房间氛围，仅此一处用衬线 |
| 集号方块 | — | 46×46，10px 圆角，`--surface2`；已看态 `--accent-soft` 底 + `--accent-ink` 字 + check SVG | 有序感与进度可视化 |
| 进度条 | `--accent` | `--accent`（装饰色，允许） | 非文字，不受 4.5:1 约束 |
| 二级 Tab | TabBar 下划线 | pill chip（44px），选中 `--accent-soft` 底 + `--accent-ink` 字 | 与顶部类型 chip 区分层级 |
| 片单网格 | — | `repeat(auto-fill, minmax(180px, 1fr))`；≤760px 强制两列 | 移动端不塌成一列 |
| 嵌入槽圆角 | `--r-md` 10px | **12px** | 与视频缩略图 10px、卡片 14px 形成中间层级 |

**内容字段裁决（2026-11-10）**：用户自建房间的剧集与电影条目只展示用户整理的元数据、原创按语、讨论和进度；不展示观看平台、合法观看入口、平台徽章或条目内播放器。普通 UGC 帖子也不附加观看平台字段。视频房间的官方外链、播放器同意与原创上传确认仍按下文规则展示。

## 3. 合规 UI 在本页的具体落点

- **上传范围**：`series` / `film` 不提供文件上传；`video` 仅本人原创视频可上传，并必须确认人物同意、无未授权音乐或影视片段；官方内容只登记外链，付费、地区受限或未授权内容不得托管。
- **视频房间外链 URL 实时校验**：`urlcheck` 三态 —— `ok`（`--good` + `--good-soft`）/ `no`（`--danger` + `--danger-soft`）/ 中性说明。白名单内通过、大陆限定平台与短链拒绝。错误文字带 `role="alert"`。此流程不应用于剧集/电影条目或普通 UGC 帖子。
- **视频四态徽章**：审核中（`--warn`）、英区无授权「僅登記 · 暫無合法入口」（`--warn`）、源站禁止嵌入「去原站看」（`--warn`）、原创已确认（`--good`）、官方外链（`--accent-ink`）。**文字 + SVG + 颜色三重指示**。不用于剧集/电影条目。
- **同意面板**：占位卡 → 告知 → 三选项 → 官方 iframe → 收起销毁 DOM。iframe 有 `title`，加载提示用 `aria-live`。
- **举报常驻**：每条 `VideoCard` / `ListingCard` 都有 44px 举报按钮，不藏进「更多」。
- **分类信息**：`ListingCard` 显示 `£` 价格、认证徽章（`--good`）、30 天过期徽章（`--warn`）、审核中状态；过期不静默消失。
- **示例文案用繁体粤语场景**（《新闻女王》、倫敦 Ealing 中超開箱），用于验证简繁混排与字体栈；状态词必须在简繁文案表里成对维护。

## 4. 编排与权限的视觉表达

- `sort_key` 由服务端生成（字典序即播放序），**前端不允许任意拖拽重排**；房主只有「上移 / 下移 / 按集号重排」三个 44px 按钮，且需显示当前排序依据。
- 追更进度 `user_progress` 默认仅自己可见：界面上必须标明「仅自己可见」，避免 UK GDPR 下的预期外公开。
- 协作编辑（`channel_collaborator`）在侧栏「房主 / 协作者」区显示身份徽章。

## 5. 本页验收点

1. 通用、剧集、电影、视频四种房间形态可预览；类型默认通用且可选、可后改；
2. 季 Tab、集序固定、标记已看与进度条即时更新；上移/下移/重排不产生非法 `sort_key`；
3. 有内容房间进入目录，加入/退订与更新通知状态可用；房主添加条目、分类信息发布（进审核 + 30 天过期）全流程可用；
4. 外链：点击 → 同意 → 播放 → 收起销毁；禁止嵌入与英区无授权两态正确降级；URL 校验三态文案准确；
5. 所有 44px 触控目标、label 关联、SVG symbol 引用、焦点环、reduced-motion 通过自动化校验；
6. 深浅色 + 420px 移动视图 + 两列片单无横向滚动；
7. 与首页并排检查品牌色、按钮配对、徽章、深色次要文字一致。

## 6. 所属官方频道

每个用户房间必须归属一个官方国家或国际频道。房间不与官方频道并列出现在顶层频道目录；有已发布内容的房间只在所属频道详情页的「这个频道里的用户房间」区公开展示；房主也能在自己的频道详情页查看空房间。房间页顶部的所属频道入口可返回父频道详情。通过房间页创建新房间时，返回主原型的创建表单，并预选当前房间的父频道；创建表单也必须要求选择所属官方频道。

## 7. v1.8 优化轮补充（2026-11-11，详见 MASTER §21）

- **所属频道（v1.9 已拍板，PRD §36.5）**：必填；可挂国际频道，或已开通国家的官方 / 平台共建频道（例如英国租房）。规则集中在首页 `canHostRooms()` 一个函数。
- **房主视图**：显示「我是房主」胶囊与房主工具条（发布到本房间、模拟其他用户加入）；房间类型切换条只对房主显示。新建房间显示「房间已创建 · 发布第一条内容并通过审核后才会公开」提示与空态 CTA。
- **用户自建房间的帖子**：不管类型是通用还是剧集 / 电影 / 视频，都先显示房间帖子列表（含审核中状态，仅作者可见），再显示类型模块。
- **加入 / 评论 / 发布**：游客先走轻注册，完成后自动回到原动作；加入状态写入共享数据，首页与房间页一致。
- **举报**：房间、留言、外链卡统一用 `ReportSheet`。
- **切换条热区**：`rs-chip` / `rs-parent` / `rs-new` 视觉 34px，`::after` 补到 44px。

## 8. v1.9 国家范围（2026-11-11，PRD §36 / MASTER §22）

- 房间的国家范围跟随所属频道：挂国际频道的房间各国可见，挂英国频道的房间只在当前国家为英国时可见。共享层 `UKCN.roomRegion(room)` 解析（房间自带 `region`，否则查主页写入的频道映射）。
- 当前国家看不到这个房间时，页面顶部显示 `CountryGuard` 占位提示，隐藏内容区，加入、发布、留言都被拦下并提示；数据保留，切回后恢复。
- 发布页的发布目标只列当前国家可见的房间。
- v2.0：房间页右下角 + 是手机端唯一发帖入口；已加入或房主时预选当前房间，游客先注册。发布页的分类只读显示为房间所属频道的分类。
- v2.6（PRD §36.16，MASTER §22.15）：导航「通知」改名「消息」，角标 = 未读私信 + 未读通知。房间帖子作者名链接到首页原型的个人主页（`?user=@handle`），旁边小「私信」跳到会话（`?page=notifications&dm=@handle`，游客先登录）；不进帖子操作行，自己的帖子不显示。
- v2.5（PRD §36.15，MASTER §22.14）：房间帖子操作行加「喜欢」「分享」（喜欢与频道里同一条帖子状态一致，游客先轻注册）；手机端下滑收起顶栏，上滑出现。
- v2.4（PRD §36.14，MASTER §22.13）：产品名改为「海外圈」：页面标题「海外圈 · 房间原型」、品牌栏 logo 字「海」、封面水印「海外圈 · XXX ROOM」。
- v2.3（PRD §36.13，MASTER §22.12）：房间帖子默认不进所属频道的「频道动态」。房主在帖子操作行看到「推到频道」（仅已公开的帖子），推后变为「已推到频道「频道名」」+「撤回推送」；非房主只看到「已推到频道」标记。移动端帖子正文与留言 15px / 1.5（MASTER §3.2）。
- v2.1：旧的就地建房表单 `roomForm`（及 `.room-form*` 样式、保存 / 取消处理）已删除；「新建房间」统一跳到首页「频道」里的新建房表单（`?tab=add&seg=create&parent=`）。房间页帖子标题、正文、留言标 `data-ugc`，简繁切换时保持原文。
