# Page Override · 三 Tab 首页（home-feed）

> 检索：先读 `../MASTER.md`（v1.7，重点 §17、§20），再读本文件。本文件规则优先于 MASTER，但**不得覆盖** MASTER §3 token 值、§7 合规 UI、§9 无障碍底线、§17 首屏信息架构、§20 房间轻量化规则。
> 对应实现：`prototype-x-style.html` v6 ｜ 功能定义：PRD §20 / §27 / §29

## 1. 页面定位

首页是全站**消费层入口**，不承担内容生产。三 Tab 的语义必须在界面上可区分，禁止混成一个信息流：

| Tab | 视觉标识 | 排序提示（必显） | 内容 |
|---|---|---|---|
| 为你推荐 | 头部 `why-dot` 推荐理由标记 + 有限列表条数 | 「频道/区域级信号排序 · 每日 07:00 更新 · 最多 12 条 · 可切到严格时间序」 | 最多 12 条；频道分数为共现 0.40、区域 0.30、活跃 0.20、精选 0.10，再乘新鲜度；已订阅降权 0.12。不得使用逐条点击、停留、点赞行为 |
| 正在关注 | 严格时间序、无重排 | 「严格按时间排序 · 仅显示你已加入的 N 个频道」 | 订阅频道内容，跨频道去重，置顶公告在前 |
| 频道 | 目录分组 + 组合包 + 开通状态卡 | 「日更新 ≥3 条才展示」 | 频道目录、搜索、收藏/取消收藏、区域包 |

## 3. 专属组件

- **`RegionBar`（唯一区域表达位置）**：一行「当前国家」+ 单个国家 chip（含开通状态短徽章 + 移除 ×，v1.9 单选不叠加）+「国际频道 · 共享」+「添加频道」+ 齿轮。可横向滚动，不换行撑高。**卡片内禁止再放区域徽章**。添加频道用于收藏感兴趣的频道，收藏项会出现在「我的频道」并可直接进入。
- **`LocationConfirmBar`**：首页不展示定位确认条及其来源说明，避免占用首屏；确认 / 手动更改 / 关闭定位等入口保留在 `SettingsPanel`。来源、精度与隐私说明在设置中可查。
- **`SettingsPanel`**：四组（播放 / 推荐与透明度 / 区域与定位 / 演示），内容始终渲染，仅 `hidden` 控制可见性，保证 DSA Art 27 参数与定位来源不因收起而丢失。
- **`SourceLine`（本页最关键的合规组件）**：一行 11px，来源名 `<b>` + 许可角标（`--line` 描边、10px）+ 原文回链 +「N 个来源」展开。多源列表必须做 `Array.isArray(sources)` 防御——此前发生过标了 `cluster:5` 却缺 `sources` 数组导致展开抛 `TypeError` 的真实缺陷。
- **`why-dot`**：头部 14px `i-spark` 图标，`role="img"` + `aria-label` + `title` 承载「频道数据 · 推荐理由」；只在「为你推荐」出现，不占独立行。
- **推荐透明度**：推荐页只披露短句和每卡理由；完整参数、关闭入口及时间序选项在顶部设置面板中一次点击可达。不得在首页右栏堆叠长篇法域/定位说明。
- **`CardJoinButton`**：未订阅用 SVG 加号图标 +「加入」实心 / 已订阅用 check SVG +「已加入」幽灵；`aria-label` 写明频道名；点击即时同步订阅、正在关注内容、Tab 计数与该频道推荐降权 0.12。图标一律使用 SVG symbol，不把 Unicode 字符当图标。
- **`MediaBlock`**：8 种布局共用同一张卡；视频 `data-playtoggle` + `data-state` + `role="button"` + `tabindex="0"`，点按画面暂停 / 继续，右下角只有时长角标与静音指示图标。
- **`ActionBar`**：回复 / 转发 / 喜欢 / 收藏 / 分享 / 举报 6 个纯 SVG 图标，`space-between`，最大宽 420px，命中区 44px；收藏用 `aria-label` 与 `.saved` 切状态，**不得改 `textContent` 把图标冲掉**。
- **`ChannelRow` / `BundleCard`**：保持在「添加频道」页，44px 频道头像、名称 + 归属徽章、描述单行省略、日更新量、加入/退订按钮。
- **`EmbedPlayerCard`**：允许出现在「正在关注」，**禁止出现在「为你推荐」**（PRD §24）。列表页只渲染静态占位卡。
- **`BottomNav`**：≤760px 出现，5 项，60px 高，z 30；面板 `padding-bottom:70px`。
- **`AutoCityTopic`（发布编辑器）**：城市话题需用户主动添加，不自动公开位置；发布前可移除，同名标签去重。定位关闭 / 未确认时不提供添加入口；城市只用于帖子标签，法域开通仍按国家判断，不申请 GPS。人在已开通国家的任何城市，仍可见该国官方频道；城市级内容筛选不能缩小国家开通范围。

## 4. 内容节奏约束（视觉层必须配合）

「为你推荐」是**最多 12 条的有限列表**，界面显示简短排序依据、更新时间（每日 07:00 本地时区）和可切换到时间序的入口。**禁止实现无限滚动**：L1 源（GOV.UK / 地方议会 / TfL）一天只有几条，无限流会露出大片空白，也会放大 NLA「聚合替代原文」的观感。密度靠事件聚类卡与 L3 用户频道补，不靠填充低质内容。

**首屏精简硬约束（§17.2）**：第一条帖子之前只允许 1 条 11px 极细提示 + X 式 Compose 框；播放偏好、DSA 参数、定位说明、原型版本号一律不得出现在这里。旧版 4 条 `section-hint` + `PlaybackPrefBar` + `demo-note` 已废止。

## 5. 本页验收点

1. 三 Tab 可切换，选中态清晰，键盘方向键可用；切 Tab 自动收起设置浮层；
2. 加入/退订即时同步内容流与计数；组合包一键加入；
3. 事件卡「N 个来源」展开/收起不抛错，缺失数据有防御；
4. 每张卡都有来源名 + 许可角标 + 原文回链 + 举报入口，且都在一行 `SourceLine` / 一行 `ActionBar` 内；
5. **每张卡右上角有加入按钮**，卡片内无区域徽章、无「来自频道」独立行；
6. **视频下方无任何播放 / 静音按钮**，点按画面能暂停 / 继续；外链卡只出现在「正在关注」，同意面板三选项完整，收起销毁 iframe；
7. 齿轮一次点击展开设置浮层，四组可读、不遮挡 Tab；关闭后首屏仍只有一行区域栏；
8. 深浅色、420px 移动视图、200% 缩放均不破版；所有紧凑按钮命中区 ≥44px 且不互相重叠；
9. 首页与房间页并排检查：按钮圆角、Tab 选中态、徽章、深色次要文字一致。

## 7. v1.8 优化轮补充（2026-11-11，详见 MASTER §21）

- **顶部空白**：SVG sprite 必须 `class="sprite"` 且 `position:absolute;width:0;height:0`，不得占文档流（此前首屏顶部多出约 156px）。
- **正在关注**：置顶公告在前，其余严格按发布时间倒序，同时间按原顺序；未关注 / 游客显示空态 + 下一步按钮。
- **创建房间表单**：房间名、类型、所属频道、「更多选项」展开状态保存在 `roomDraft`，搜索、切 Tab、重渲染都不清空；类型选「剧集」后提交即为 `series`。从频道详情「在此创建房间」进入时预选该频道，所属频道为必选（官方 / 平台共建两组）。
- **底栏 5 项 + 发布 FAB**、「我的」页、三屏轻注册、举报面板、四类状态均按 MASTER §21 实现。
- **发帖入口（v2.0）**：手机端（≤760px 与移动预览）首页内容流不显示内嵌发帖框，只用右下角 + FAB；桌面端保留内嵌发帖框。频道详情内点 + 预选投稿到该频道，游客点 + 先注册。
- **频道详情**：返回按钮放在封面之前（不再压在封面上）；官方频道带 SVG 认证标；房主可见自己未公开的空房间（「未公开」徽章）。

## v1.9 国际化三层模型（2026-11-11，PRD §36 / MASTER §22）

- **当前国家单选**：英国下首页、发现、目录同时有国际频道与英国分类频道；切到未开通国家或关闭定位后只剩国际频道，不出现任何英国分类数据。
- **国际频道各国一致**：国际频道的帖子、详情在任何国家下内容相同。
- **区分放在频道层**：目录分组、频道行 `RegionBadge`、频道详情 `ScopeTag`（「国际 · 各国共享」/「英国频道 · 仅英国」）；内容卡片仍不加区域徽章。
- **暂停而非删除**：其他国家的关注、收藏、房间保留，显示「另有 N 个…属于其他国家，切回后恢复」。
- **创建房间**：所属频道必填，下拉只列国际频道与当前开通国家的官方或平台共建频道；分类只读显示为继承结果（跟随所属频道，无选择控件）；提示房间名与简介需审核。
- **手动切换国家（v2.0）**：设置里可切到任意已开通国家，不要求与定位一致。
- **桌面内嵌发帖框的信息类帖子**：分类只读，发到房间时跟随房间所属频道，发到我的动态不归入分类。
