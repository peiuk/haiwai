自动定位与开通权限

PRD §28 / MASTER §16

App 首次进入自动推断国家级大区域，只决定默认展示哪个频道包；绝不启用任何法域的官方频道。定位用 CDN 边缘 IP 粗粒度推断，不申请设备 GPS 权限、不存 IP 原文与经纬度。区域是官方的合规容器，频道是用户的表达空间：区域 / 官方包 / 官方频道由平台在法域风险评估后创建，用户可自建频道，包括官方未开通的地区。

定位信号优先级（两个用途，禁止混用）

内容区域（我在哪）：已保存的明确选择 → CDN 边缘 IP 国家 → 系统语言 / 时区 → 自选 → GLOBAL 兜底
法域参考（我受谁约束）：商店地区（Apple ID / Play 账号国）、账号国、上架地区、用户声明
App Store 商店地区跟账号国走，不跟设备语言、GPS 或 IP；移民用户常滞后于实际所在地，因此只能作弱信号。VPN / 漫游误判靠在设置中手动切换国家纠正。
ICO 将「不识别个人的城市 / 区域级粗粒度定位」列为可免 PECR 同意的统计目的例外；但 IP 仍属 UK GDPR 个人数据，须透明、最小化、可反对。设备 GPS 精确定位才需要单独同意与权限弹窗 —— 本产品不用。
可交互活示例：打开 prototype-x-style.html v6，顶部定位条可确认 / 手动改 / 关闭；右上角齿轮的「区域与定位」分组可模拟定位到未开法域（日本）验证回退；「添加频道」页可点「申请开通」。区域信息只在顶部出现，帖子卡内不再重复。

裴总第十一～十三轮反馈的合成：用户创建多个「房间 · 小圈子」（一部剧一个房间、一部电影一个房间），其他用户可留言评论、@ 用户名、# 关键词；发帖没设关键词时官方 AI 自动补最多 5 个；房间不一定视频、没有类型与版权确认，想建就建；房间有内容就显示在频道目录，右上角一键加入，加入后更新有通知。

通知中心 + 留言评论 + @/# + AI 关键词（§30 已冻结）

更新通知：加入房间 / 频道即订阅；通知进「通知」中心 + 未读角标，`channel_notification` 摘要（「房间 X 新增 1 条内容」），不带原文 / 单集 / 外链。
留言评论：房间「留言 · 讨论」Tab，@ 人 / # 关键词 / 举报，共用 24h 下架 SLA；评论不进推荐流、不推送、不做算法放大。
官方 AI 关键词：仅用户 0 关键词时生成 ≤5 个，逐个标「AI」角标、可改可删；用户填 ≥1 个则 AI 完全不介入；关键词不进推荐打分、不进画像。
红线不变：房间永不带认证徽章、永不进官方区域包、永不进「为你推荐」个性化流（频道目录 ≠ 推荐流）；原创视频上传仍强制版权确认；通知删除 / 24h SLA / 重复侵权政策一条不减。
