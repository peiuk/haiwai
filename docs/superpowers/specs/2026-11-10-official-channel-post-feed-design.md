# 官方频道帖子流 UI 设计

日期：2026-11-10  
状态：HTML 原型完成，待视觉确认

## 意图

让用户进入官方频道后，快速辨认官方频道身份、找到最新内容，并能在不被来源说明打断的情况下阅读帖子。沿用现有 CN Channels 原型和设计系统。

## 范围

- 保留频道返回入口、官方认证标识、频道简介和加入状态。
- 帖子采用混合卡片：文字帖紧凑；含图片、原创视频或第三方嵌入的帖子按现有媒体规则展开。
- 帖子头部展示作者/官方频道身份与发布时间；正文展示标题、内容、关键词。
- 帖子尾部保留回复、转发、喜欢、收藏、分享、举报操作。
- 频道详情帖流不重复显示来源、许可或来源聚合区域；该内容不影响产品审核记录。
- 官方第三方视频维持静态占位，须点击后才询问并加载；不预加载 iframe。

## 非目标

- 不改变推荐、订阅、区域权限、审核或媒体播放规则。
- 不新增依赖、色板 token 或真实媒体资源。
- 目录中的用户房间和首页推荐卡不随本次原型改变。

## 方案比较

- 紧凑新闻列表：扫读快，但混合媒体时内容关系不清。
- 完整大卡片：信息层级强，但纯文字帖子会显得冗长。
- **混合卡片（选用）**：文字保持紧凑，媒体依帖子类型展开；保留阅读与浏览效率。

## 验收

- 官方身份、频道简介、加入状态位于频道头部。
- 帖子按时间线卡片呈现，文字与媒体层级清楚。
- 帖子 UI 无来源/许可行；视频仍使用既有静态占位和点击加载。
- 375px 移动宽度可读，操作触控目标不低于 44px。
