# 官方频道与用户房间层级设计

日期：2026-11-10  
状态：依用户“继续”授权实施

## 意图

建立清楚的空间层级：平台创建的国家 / 全球官方频道是一级入口，用户创建的房间是某个官方频道下的二级空间。用户房间不与官方频道并列出现在发现目录。

## 目标

- 每个用户房间必须关联一个官方频道；取消独立房间和空父级状态。
- 有已发布内容的房间只在所属频道详情页的“用户房间”区展示；房主也能在自己的频道页看见空房间。
- 创建表单把归属频道设为必填；提供“全球华人交流”官方综合频道作为默认归属。
- 从频道详情可以直接创建挂在该频道下的房间；打开房间后可返回所属频道。
- 官方频道发现列表与组合包只包含频道，不把房间伪装成频道。

## 非目标

- 不改变频道帖子的发布和订阅规则。
- 不将房间帖子汇总为所属频道帖子，也不把房间内容放入为你推荐。
- 不更改现有房间加入、通知、类型或内容门槛。

## 方案与取舍

1. **房间作为一级目录的并列卡片**：容易发现，但继续模糊频道和房间的身份区别。
2. **房间嵌套在官方频道（选定）**：频道页内列出所属房间；结构直观，创建时需要选择父频道。
3. **频道详情不列房间，只能用房间名搜索**：主目录更简洁，但用户难以理解房间与频道的归属关系。

采用方案 2。为了确保每个房间都有合法归属，新增全球综合官方频道作为创建表单默认值；房主可改选其他官方频道。

## 约束

- 仅官方频道可作为父级；不允许房间套房间。
- 只有有已发布内容的房间对其他用户可见；房主可在自己的频道页看见空房间并继续维护。
- 归属频道显示名称及来源身份；房间保留“用户自建 · 非官方”标识。
- 更新 PRD §34、房间页规范与单文件 HTML 原型，明确覆盖 §31 / §32 中“可不挂靠”和一级房间目录旧规则。

## 验收

- 发现页和添加页的频道目录 / 频道包不出现房间卡片或房间伪频道。
- 用户创建房间必须有父级频道，提交按钮受房间名和父级两项约束。
- 频道详情显示该频道下所有公开房间及房主自己的空房间，展示加入状态及房间名。创建空房间后返回父频道详情。
- 房间页能显示所属频道，并可返回该频道详情。
- 现存示例房间全部有官方父频道，且视频 / 通用 / 剧集 / 电影示例均能归类。
