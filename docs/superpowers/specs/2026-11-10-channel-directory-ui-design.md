# 频道加入目录 UI 优化设计

日期：2026-11-10
状态：待用户审阅

## 意图

让用户更快找到值得加入的频道，同时在点击加入前获得足够的频道内容线索。沿用现有 CN Channels 原型和设计系统，不改变频道订阅或推荐规则。

## 目标

- 进入频道目录后，优先看到可用的频道组合包与频道搜索/筛选。
- 官方频道按地区分组；用户频道和用户房间易于区分。
- 频道卡一眼可读：频道名、简短描述、活跃度、最近帖子线索和明确的加入状态。
- 加入操作保持单击完成，已加入状态可直接退订。
- 保留创建房间、用户房间目录、区域包及法域说明，但降低次要信息的首屏占比。
- 移动端卡片紧凑可扫读，按钮触控目标不小于 44×44px。

## 非目标

- 不改变订阅后的内容流、推荐算法、通知策略或用户权限。
- 不将平台政策/区域开通说明删除；改为次要位置或可展开说明。
- 不把频道包变成强制新手步骤；用户仍可逐个加入。

## 方案比较

- **纯快捷列表**：每行放名称、简介和加入按钮；信息密度高，但加入前缺少内容判断线索。
- **内容预览卡片**：每个频道展示帖子样例和更多元数据；判断更充分，但会让目录明显变长。
- **混合目录（选定）**：顶部提供搜索/筛选与紧凑频道包；频道列表维持轻量卡片，点频道名看详情和帖子；政策说明折叠。兼顾快速加入与内容预览。

## 页面结构

1. 保留「频道目录 / 创建房间」分段。
2. 频道目录首屏放地区选择、搜索与分类筛选；提供一行简洁说明和清晰的已加入状态。
3. 将组合包提升至频道列表之前，改成横向紧凑卡，名称、频道数和一键加入状态易读。
4. 官方频道按地区分组，频道行增加近期内容标题或更新时间；加入按钮固定右侧，频道名称进入详情页。
5. 用户房间放在官方频道之后，保留「用户自建 · 非官方」标识、最近更新和右侧加入按钮。
6. 区域开通/法域信息放入可展开的「地区与平台说明」，减少滚动干扰。
7. 保留搜索无结果状态、加入后的即时反馈、深浅主题及现有移动端导航。

## 约束与参考

- 在 `prototype-x-style.html` 的 `renderAdd()` 与现有频道行/房间卡基础上实现。
- 复用 `design-system/MASTER.md` v1.7 与现有 CSS tokens，不新增色板和外部依赖。
- 产品行为以 PRD §29、§32 为准：卡片右上角加入、房间有内容才展示、加入后有更新通知。

## 验收重点

- 用户从目录可直接加入频道，也可点击名称预览详情后再加入。
- 首屏能看见搜索/筛选和至少一组频道组合包；政策说明不会挤占频道列表。
- 卡片可区分官方频道、用户频道和用户房间，加入状态清晰且一致。
- 375px 宽度下筛选可横向滚动，频道标题不被加入按钮遮挡。
- 搜索无结果时有可理解的恢复提示。
