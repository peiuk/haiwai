# 项目逻辑与设计优化审查

审查日期：2026-11-10  
审查范围：产品逻辑、设计规则、首页 HTML 原型与现有自动化门禁

## 规则增补（2026-11-10）

- 官方开通范围以国家法域为单位；已开通国家内所有城市均属于开通范围，城市级频道包只是内容编排，不是第二道开关。
- 用户确认粗粒度定位后，发帖编辑器自动预填 `#城市名`，可在发布前移除；定位关闭或未确认时不加城市话题。

- 当前导航用词：「创建房间」入口显示为「频道」；个人入口「我的频道」显示为「我的房间」。仅改 UI 名称，创建对象仍是用户房间。

## 结论

产品主线成立：用户主动订阅频道，关注流按时间排序；推荐流提供有限、可解释的内容发现；频道目录与房间承接主动探索。区域偏好只决定默认频道包，法域是否开通由平台治理。来源、许可、原文链接与播放器同意流程是必要的信任与合规界面。

眼下的主要风险是产品规则与实现文档之间的版本漂移，以及首版范围偏大。原型适合验证交互，不代表持久化、账号、权限、采集和审核系统已经实现。

## 统一产品规则

1. **为你推荐**：最多展示 12 条，按可解释的频道分数和内容新鲜度排序；频道分数沿用 PRD 的订阅共现 0.40、区域匹配 0.30、频道活跃 0.20、编辑精选 0.10。已订阅频道内容降权 0.12，避免与关注流重复。
2. **关注流**：仅展示已加入且未静音频道的内容，严格按时间倒序；置顶公告按既定规则置顶，不使用逐条点击、停留或点赞行为画像。
3. **频道推荐与内容推荐是不同入口**：频道共现用于发现频道；推荐页给出内容卡。每条推荐卡仍展示推荐理由，并保留来源、许可、原文链接和举报入口。
4. **区域与法域分离**：用户区域偏好可叠加；官方频道及官方区域包是否开通由平台按法域评估决定。用户自建频道不自动成为官方频道。
5. **说明文案从首页右侧移除**：将长篇定位、法域、推荐参数说明留在设置面板和目录的「地区与平台说明」中；首页右侧保留搜索、频道发现等直接任务。内容卡的来源证据和第三方播放器的事前同意仍保留。

## MVP 建议

### 阶段 A：可验证原型

- 用现有独立 HTML 展示首页、频道目录、频道详情、房间和发布流程。
- 所有模拟数据与模拟交互明确标记为演示；不以 toast 代替真实提交成功或举报工单。
- 以核心流程走查和 375px / 桌面截图确认信息层级。

### 阶段 B：英国首发最小产品

- 先做英国首启法域、3–5 个可靠内容源和少量高密度频道。
- 交付游客浏览、轻注册后继续加入、订阅/退订、严格时间关注流、频道搜索与详情、来源标注和基础举报处理。
- 在该闭环稳定前，不同时启用其他地区的官方频道；多区域数据模型可以先保留。

### 阶段 C：社区与运营能力

- 增加用户房间、发帖、投稿审核、通知频控与编辑修正回流。
- 以审核处理时长、内容质量、频道活跃和新用户加入数作为上线初期指标。

### 阶段 D：新增法域

- 每个新法域独立完成风险评估、内容源许可、条款/通知渠道与下架流程后再启用官方频道。

## 设计与工程约束

- `design-system/MASTER.md` 是全局视觉和组件准绳；`design-system/pages/*.md` 只写页面覆盖规则；`tokens.css` 是颜色、尺寸等 token 的唯一来源。
- 旧页面说明若与 MASTER 或现行 PRD 冲突，先标为历史参考，再决定是否迁移；不并行维护第二套设计 token。
- 原型 HTML、正式 API/数据库和生产服务要分别验收。轻量 DOM 门禁验证渲染与状态逻辑，不替代真实浏览器、服务端授权、持久化和真实内容源验证。
- 推荐与关注状态、搜索结果、游客加入意图、空状态和错误恢复都要写成用户可见的验收标准。

## 本轮检查

- WCAG token 对比度、UI 静态/动态、区域逻辑、媒体逻辑、定位治理、房间逻辑 6 组门禁全部通过。
- 房间门禁现在验证 `publishedCount > 0`，并用一个零内容房间样本确认它不会进入目录；不再依赖固定说明文案。
- 定位门禁验证首页不渲染长篇右栏说明，同时确认定位、法域治理说明仍在设置与目录入口。关闭定位后，设置面板显示全球兜底并隐藏旧定位来源。
- 已用真实浏览器查看深色桌面、深色 420px 首页和浅色桌面；推荐说明已压成一行。截图保存在 `output/playwright/`。

# 核心业务逻辑与交互闭环优化（2026-11-12，v2.7）

针对实测中复盘出的 6 处逻辑与体验断点，已将规格全面录入 PRD §36.17 与 MASTER v2.7：

1. **社群动态激活**：已加入房间帖子时间倒序并入首页「正在关注」，带 `来自已加入的房间` 来源跳转，支持静音过滤。
2. **分类信息闭环**：发布者手动「标记已租出 / 已售出」结案，卡片与详情盖印章并关闭联系方式；临期或过期未结案提供「一键刷新（重置 30 天）」。
3. **交易咨询直通通道**：分类信息「私信咨询」自动携带房源卡快照，免陌生人「消息请求」拦截，直达房东正式会话。
4. **房主推送级联失效**：频道动态实时比对原帖发布状态，原帖删除、驳回或下架时，推送卡片自动失效隐藏。
5. **跨国漫游浏览模式**：未开通国家用户允许主动选择浏览英国站内容，保障准留学生出行前租房和资讯消费需求。
6. **敏感联系方式频控**：单日上限 5 次，剩余额度透明展示并弹窗二次确认，防范恶意爬虫与电诈。
