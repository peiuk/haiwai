## 二、新增流程

1. **移动端底栏**：首页 / 频道 / 发现 / 通知 / 我的，共 5 项，带文字；右下角发布 FAB。收藏、我的房间收进「我的」。桌面左栏同步加「我的」。
2. **「我的」页**：资料卡、我的房间、我的帖子（带审核状态）、收藏、我的举报、设置（简繁、主题、播放与定位）、隐私与数据（导出 JSON、同意记录、删除账号二次确认）、演示工具。
3. **三屏轻注册**：手机号或邮箱 + 验证码（演示码 246810）→ 18+ 与条款、隐私（营销默认不勾）→ 昵称、头像色、简繁。加入、关注、发布、评论、查看联系方式都会触发，完成后自动回到原动作。同一号码再次验证即登录原账号。
4. **共享演示数据**：三个页面共用 `shared/ukcn-shared.js`（内联副本，零外部资源），一个 localStorage key `ukcn.demo.v1`。已跑通：登录 → 创建房间 → 发帖（首页编辑器或 `publish-content.html`）→ 审核中 → 模拟审核通过 → 房间和频道详情可见 → 模拟其他用户加入 → 收到通知。「我的 · 演示工具」里有重置演示数据。
5. **独立发布页**：新增「发布到」（我的动态 / 我的房间，从房间进入时自动选中该房间）；游客先轻注册；发布后显示「已提交审核」卡，可去房间、模拟通过、再发一条；简繁跟随账号偏好；举报走统一面板。
6. **状态**：空态（带下一步按钮）、加载骨架屏（260ms）、错误态 + 重试（「模拟下一次网络错误」，作用于通知、发布、举报、验证码、导出）、审核中 / 已公开 / 未通过徽章。
7. **举报流程**：选原因（6 项，「其他」需补充）→ 提交 → 完成页（原因、工单号、处理时限）；失败保留选择。首页、房间、留言、外链卡、发布页都用同一个。

2. **私信列表与会话**：列表顶部一行小字「演示：私信只保存在本机，真实发送需要后端」；会话行有头像、名字、时间、预览、未读点。会话里可以发文字（最多 1000 字）和图片；没有已读回执、没有语音（页面上写明）。手机端会话里隐藏 +，输入框贴在底栏上方。
3. **消息请求**：不是你关注的人第一次私信你，先进「消息请求」；接受前不能回复，可以接受、删除（先确认）或拉黑。
4. **拉黑和举报**：每个会话头部都有「拉黑」（先确认，会话随即隐藏，对方发不进来）和「举报」（走统一举报流程，类型「私信」）。
5. **私信入口**：频道动态里的房间帖子和房间页帖子，作者名旁一个小「私信」（不在回复 / 喜欢 / 分享那一行，自己的帖子不显示）；点作者名进个人主页，主页有「关注 / 私信 / 拉黑 / 举报」和 TA 的帖子。
6. **「我的 · 设置 · 私信」**：「陌生人私信 允许 / 关闭」，关闭后只收你关注的人的私信；拉黑名单可一键解除。演示工具加「模拟陌生人发来私信」，用来看开关效果。
7. **游客**：点「私信」先弹登录 / 注册，完成后直接进入会话（和「喜欢」一样续上）；游客的「消息」页只显示登录引导。
8. **数据**：示例 2 个会话 + 2 条消息请求，存在 UKCN 共享层（`dms` / `follows` / `blocked` / `dmPrefs`），三个原型页共用；导出数据带私信文字，删除账号一并清空。

**文档**：PRD 版本行改为 §36.9 – §36.16，新增 §36.16（含服务端建议的表结构与投递判定顺序），§37 加一行；MASTER 升 v2.6，新增 §22.15（`MessagesSegment` / `DMList` / `DMRequestRow` / `DMThread` / `DMComposer` / `DMChip` / `ProfileHeader` / `DMSettingsRow`），变更记录加一行，没有新增 token；`pages/home-feed.md`、`pages/collection-room.md`、`pages-collection-discovery-notification.md`（通知页一节注明已成为「消息 · 通知」分段）补说明。
